FiveM server mod: Players respawn near other players in multiplayer, or near where they died in singleplayer.

Install: Place the respawnPlus folder in the server's resources folder and add "start respawnPlus" to server.cfg

Inspired by syncpos by simpleC0de (github)/PeterRameder(cfx.re forums), and using snippets shared by VenomXNL and MetoPatel on the cfx.re forums.
